# Laravel Notification Inbox

In local and staging, catch every non-mail notification your Laravel app sends (web push, FCM,
Slack, Microsoft Teams, Telegram, Discord, SMS, broadcast) instead of delivering it. Each one shows
up in a single inbox as a realistic preview, and your tests can assert against the captured
payloads. It refuses to run in production.

> **Status:** in development. The first release is not on Packagist yet.
